# Turtles

[Pylon](https://pylonmc.github.io/) addon that adds programmable
computers with the easy-to-learn [Jactl](https://jactl.io/)
programming language, inspired by [ComputerCraft](https://computercraft.cc/).

## Status

The addon is in active development and is **not ready** for production
environment. Run it only on a test server! There is a high chance of
breaking changes coming up before the first stable release.

Proper server admin and developer guide will be released together
with the first stable version.
